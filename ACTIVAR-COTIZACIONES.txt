ARBOLITO: ACTIVAR LOS CINCO PRECIOS

1. Subí el contenido del ZIP a la raíz de ricardo-3/Arbolito-BR, rama main.
   Incluí scripts/actualizar_pix.py y .github/workflows/cotizaciones-pages.yml.
   La carpeta .github puede estar oculta: revisá que aparezca en el repositorio.
   Conservá tus imágenes existentes en imagenes/.
2. Settings > Pages > Source > GitHub Actions.
3. Actions > Arbolito - cotizaciones y Pages > Run workflow > main.
4. Esperá que build y deploy terminen en verde. Recargá tu web.

La consulta se programa aproximadamente cada 15 minutos; puede demorarse.
No es una ventana en vivo. Si falla, la web anterior permanece publicada.
Los visitantes no consultan Compara Pix: reciben una tabla estática de Pages.
Al tocar un precio se copia en la calculadora; tocá Calcular para obtener el total.
Si dice Consulta antigua, confirmá en Compara Pix o en tu billetera.

No hay API de cotizaciones de pago ni claves. Sí hay consultas públicas de red
y trabajo programado en GitHub Actions. Para publicar gratis esta configuración
usa un repositorio público y runners estándar de GitHub.

Guía completa y banners: GUIA-GITHUB-Y-BANNERS.txt.
